Bluebox: Despliegue de Proxmox VE con Tailscale

Junio 2026  ·  5 min de lectura

Este documento describe el proceso de instalación y configuración inicial de Proxmox VE sobre un Dell Latitude, junto con la integración de Tailscale para acceso remoto seguro y la configuración de split tunneling en ProtonVPN para evitar conflictos de conectividad.

El objetivo es establecer una base sólida sobre la que desplegar contenedores LXC, máquinas virtuales y servicios self-hosted, todo ello accesible de forma remota sin depender de la red local.

1. Descarga de Proxmox VE

Desde el equipo principal, se descargó la ISO del instalador de Proxmox VE desde el sitio oficial. Posteriormente, se grabó en una memoria USB mediante dd:

sudo dd if=proxmox-ve_*.iso of=/dev/sdX bs=4M status=progress

También puede utilizarse Rufus en Windows para este paso.

2. Instalación en el Latitude

Se conectaron teclado y monitor al Latitude. Se arrancó desde la USB pulsando F12 para acceder al menú de boot. Durante el instalador se configuraron los siguientes parámetros:

  • Disco de destino: SSD 256 GB
  • Hostname: bluebox.lab
  • IP estática: 192.168.10.78/24
  • Gateway: IP del router local
  • DNS: 1.1.1.1

Es importante conectar el cable de red antes de iniciar la instalación. De no hacerlo, el instalador asigna direcciones IP incorrectas al no detectar la red a tiempo.

Una vez finalizada la instalación, se retiró el USB y se reinició. El panel de administración quedó accesible desde la red local en https://192.168.10.78:8006.

3. Configuración de repositorios

Proxmox VE incluye repositorios empresariales por defecto. Sin una suscripción activa, estos repositorios devuelven errores. Para resolverlo, se debe acceder a Updates > Repositories en el panel web y seleccionar la opción pve-no-subscription. Es recomendable realizar este cambio inmediatamente después de la instalación.

4. Instalación de Tailscale

Desde la shell del nodo en el panel de Proxmox, se ejecutaron los siguientes comandos para instalar y autenticar Tailscale:

curl -fsSL https://tailscale.com/install.sh | sh
tailscale up
tailscale ip -4

La IP asignada por Tailscale (100.114.37.9 en este caso) es la que se utilizará para todas las conexiones remotas posteriores. Se recomienda registrarla para su uso futuro.

5. Split tunneling en ProtonVPN

ProtonVPN en modo túnel completo interfiere con las conexiones a través de Tailscale, ya que todo el tráfico se redirige a través de la VPN. Para solucionarlo, es necesario configurar el split tunneling para excluir el rango de direcciones de Tailscale:

  • En ProtonVPN, acceder a Settings > Connection > Split Tunneling
  • Activar el modo "Exclude selected IPs"
  • Añadir el rango 100.64.0.0/10
  • Aplicar los cambios y reconectar la VPN

Tras esta configuración, el panel de Proxmox es accesible desde cualquier ubicación a través de https://100.114.37.9:8006, incluso con ProtonVPN activo.

6. Problema con el firewall de datacenter

Durante las pruebas de conectividad remota, las conexiones entrantes a través de Tailscale fallaban con el mensaje "connection refused". El origen del problema era la activación del firewall a nivel de datacenter, que entraba en conflicto con las reglas definidas a nivel de nodo.

La solución consistió en desactivar el firewall a nivel de datacenter y mantener únicamente las reglas configuradas directamente en el nodo. Esto eliminó los conflictos y permitió el acceso remoto sin incidencias.

7. Resumen de configuración final

  • Hipervisor: Proxmox VE instalado y operativo en Dell Latitude
  • Acceso local: https://192.168.10.78:8006
  • Acceso remoto: https://100.114.37.9:8006 vía Tailscale
  • VPN: Split tunneling configurado — ProtonVPN no interfiere con Tailscale
  • Firewall: Reglas activas solo a nivel de nodo, sin conflictos
  • Hardware: Latitude conectado a corriente y a la red — sin intervención física necesaria a partir de este punto
